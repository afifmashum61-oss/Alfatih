# 📖 Al-Fatih Qur'an Academy - Platform Kursus Ngaji & Belajar Online

Platform Frontend modern, mobile-first, dan sepenuhnya responsif untuk layanan kursus ngaji & belajar Al-Qur'an online (**Al-Fatih Qur'an Academy**). Dibangun menggunakan **React**, **Vite**, **Tailwind CSS**, dan **Lucide Icons**.

---

## 🌟 Fitur Utama

- 📱 **Mobile-First & Responsive Layout**: Dioptimalkan khusus untuk layar HP, Tablet, dan Desktop.
- 🎨 **Desain UI/UX Modern**: Mengusung skema warna Forest Emerald Green (`#1B4332`) & Warm Amber Gold (`#EB9414`), dilengkapi *glassmorphic sticky navbar* dan *mobile side drawer menu*.
- ⚡ **Running Marquee Ticker**: Banner program bergerak kontinyu dengan animasi CSS.
- 📖 **Simulasi Tajwid Interaktif**: Fitur interaktif untuk mendengarkan contoh audio makhraj & tajwid Ustadz.
- 👨‍🏫 **Profil Pengajar Bersanad**: Kartu profil tim pengajar (Ustadz Afif Ma'shum, M.Pd & Ustadzah Iva Makhmudah, S.Pd) dengan lisensi sanad dan fashohah.
- 💬 **Integrasi WhatsApp Direct**: Formulir trial gratis 1-on-1 yang langsung mengarahkan pesan pendaftaran ke WhatsApp Admin.

---

## 🚀 Cara Menjalankan Aplikasi di Lokal

### 1. Clone Repository
```bash
git clone https://github.com/USERNAME/alfatih-ngaji-online.git
cd alfatih-ngaji-online
```

### 2. Install Dependensi
```bash
npm install
```

### 3. Menjalankan Server Pengembangan (Dev Server)
```bash
npm run dev
```
Buka browser Anda di `http://localhost:3000`.

### 4. Build untuk Produksi
```bash
npm run build
```
